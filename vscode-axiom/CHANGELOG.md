# Change Log

All notable changes to the Axiom VS Code extension will be documented in this file.

## [0.1.0] - 2025-10-12

### Added

- Initial release
- Syntax highlighting for Axiom (`.ax`) files
- Support for all Axiom keywords: `fn`, `return`, `if`, `type`, `typeof`
- Highlighting for all data types: `int`, `float`, `string`, `bool`, `null`, `void`, `array`,
  `object`, `function`
- String literals with single and double quotes
- Number literals (integers, floats, hex)
- Comment support (line and block comments)
- Operator highlighting (arithmetic, comparison, logical, ternary, arrow)
- Function declaration and call highlighting
- Auto-closing brackets, quotes, and parentheses
- Code folding support
- Indentation rules

### Features

- Complete TextMate grammar for Axiom
- Language configuration for editor features
- Snake_case variable highlighting
- CamelCase function highlighting
